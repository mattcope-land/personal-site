date: 2026-08-28T10:00:00-04:00
summary: The site is Markdown files in a git repo, rendered by Hugo, hosted on Cloudflare Pages. No database, no CMS.
---

This is a sample essay. Essays have titles, a summary line, and a stable URL based on their slug. They show up in the stream with their title linked to the full post.

The whole site is just Markdown files in a git repository. Hugo turns them into HTML. Cloudflare Pages serves the HTML. If any of those tools disappeared tomorrow, the Markdown files would still be there &mdash; ready to be republished with any other static site generator.
