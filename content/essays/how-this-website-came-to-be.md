title: How this website came to be
date: 2026-08-31T22:40
summary: Seeking a more future-proof format
---

I've bounced around other people's platforms for as long as there have been platforms. X/Twitter, Facebook, LinkedIn. Substack. Wordpress (self-hosted and managed). Micro.blog and Bear. There have probably been others. My enthusiasm for each of them waxed and waned.

They’re all great. Any issue was mine.

Given my propensity for bouncing around, I thought this time I’d try a more “future-proof” format: plain text files in folders served as static HTML.

No database. No platform. No app.

...kind-of.

The no database part is accurate. But there are still some things that look a little like platforms (GitHub, Cloudflare). There are some apps, like iA Writer.

But the idea is that any one of these can be hot swapped with relatively little hassle.

Now, the real magic is, of course, that I’m writing this in the middle of 2026 and AI coding agents are real. I type (or speak!) plain English into my computer and out pops a real, working website. Doing this same thing more than about 9 months ago was totally *possible* for someone like me, just not *plausible*.

I’ve learned a ton already just getting the basic site online. It’s been a fun exercise and I like the tinkering. 

For now. We’ll see what the future brings.
